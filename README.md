## Selected projects

### 🐑 [Sheepy World: A Cheeky Tale](https://github.com/goncaloterroso25-create/Sheepy-World)

**A game made for my girlfriend as a gift for our first anniversary.**

Its world was built around shared memories, places and small personal details. It became a complete pixel-art exploration game with interconnected regions, dialogue, memory restoration, a Scrapbook, cats and a post-game **Together Mode**, with persistent saves, keyboard and controller support, and a native Windows release.

The GitHub repository contains a separate **sanitized public edition**: private photographs, videos, messages and identifying details were removed, generalized or replaced while preserving the game and its systems.

**My contribution:**

- **Concept & game design:** overall direction, world structure, progression, dialogue and interaction design.
- **Visuals & interface:** UI, visual direction and how information and interactions are presented.
- **Original music:** soundtrack composition, production and integration.
- **Sound design & curation:** bespoke sounds for the Scrapbook, inventory, doors, UI and other interactions; selection and integration of the wider sound and ambience palette.
- **Development & release:** systems design, iterative AI-assisted implementation, runtime and gameplay QA, controller and Windows-build testing, and preparation and validation of the public edition.

**Technologies:** TypeScript · Phaser · Vite · Tauri · Vitest

[**Repository →**](https://github.com/goncaloterroso25-create/Sheepy-World) · [**Windows release →**](https://github.com/goncaloterroso25-create/Sheepy-World/releases/tag/SheepyWorldV1)

### ❄️ INVERNØ · Official website

An ongoing collaboration with **INVERNØ**, an electro / dark / rock project from Vila do Conde. My work spans visual identity, photography and the design, development and maintenance of the band's website.

The site brings music, concerts, photography and booking into one place, with content management so updates can be handled without editing code.

**Main features:**

- Music and releases, live dates and concert content.
- Photography galleries and booking/contact flows.
- Portuguese and English content, responsive layouts and motion.
- A **Payload CMS administration panel** with workflows for managing the band's content.

I continue to **maintain and support the site**, add features and refine its public experience and administrative workflows as the band's needs change.

**Technologies:** Next.js · TypeScript · Payload CMS

**A documented public GitHub repository is coming soon.**

[**Visit invernomusic.com →**](https://www.invernomusic.com)

### 🧹 [Sweep](https://github.com/goncaloterroso25-create/Sweep)

An Android storage-cleanup app that groups accessible files into categories such as duplicates, large files, old downloads, installers, archives, screenshots and empty folders, with review before deletion.

**My focus:** product concept, feature definition, UX/UI and interaction design, testing on physical Android devices, investigation of device-specific behaviour, and iteration and release decisions.

The native Android implementation was **heavily AI-assisted**. Kotlin and Jetpack Compose are technologies used in this project; my contribution centred on directing, testing and refining the product.

**Implementation:** Android · Kotlin · Jetpack Compose

[**Explore Sweep →**](https://github.com/goncaloterroso25-create/Sweep)
